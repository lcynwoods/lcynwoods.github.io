Experimental design

  • Searches performed in DIA-NNv1.91
  • Summary data analysis performed in Python
    • Key packages: Pandas, Polars, Plotly, Matplotlib, Scikit-learn
  • Tests of differential abundance performed in R
    • Key packages: DAPARv1.34.5, Tidyverse, Limma
  • Overrepresentation analyses performed in Python and GO term clustering performed in R
    • Key packages: GSEAPy, rrvgo
  • Plots produced in Python

A note on Limma tests for differential abundance

Due to large batch effects, limma::removeBatchEffects in R was used prior to differential abundance analysis.

Please keep this in mind in interpretation of results.
